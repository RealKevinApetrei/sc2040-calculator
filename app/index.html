How to use

Second functions

Press SHIFT then a key for the gold label above it. Press ALPHA for the red letter (memory A–F, X, Y, M).

Modes

MODE1 COMP (normal) · 2 SD (statistics) · 3 REG (regression)
MODE ×21 Deg · 2 Rad · 3 Gra
MODE ×31 Fix · 2 Sci · 3 Norm (then a digit)
MODE ×4Disp: a b/c or d/c fractions, Dot or Comma
SHIFT MODECLR: 1 Memory · 2 Mode · 3 All

SHIFT RCLSTO: save the answer into A–F, X, Y or M

Statistics (SD / REG)

Enter each value and press M+. In REG mode type x , y then M+. Add a frequency with SHIFT , (;). Results: SHIFT 1 S-SUM, SHIFT 2 S-VAR (use ▶ for more pages). ▲▼ browses the data.
